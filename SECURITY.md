# Security policy

To report a suspected vulnerability in the encrypted Git backup plugin or its
package feed, open **Security → Advisories** and choose **Report a vulnerability**
if GitHub offers it. Otherwise email [contact@vhco.pro](mailto:contact@vhco.pro)
with a brief summary, the affected version if known, and the potential impact.
Ask for a secure way to share sensitive follow-up.

Keep vulnerability details out of public issues. Keep firewall exports,
backups, credentials, and identifying host or repository details out of the
initial report. We'll coordinate disclosure with you.

The [installation guide](docs/installation.md) explains how to verify the
public key used by the native `pkg` catalogue.
